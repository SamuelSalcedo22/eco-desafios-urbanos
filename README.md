# Eco-Desafíos Urbanos

App móvil de micro-voluntariado urbano. Los usuarios reciben misiones (limpiar un parque, ubicar puntos de reciclaje, reportar espacios deteriorados), suben evidencia fotográfica y ganan puntos. La evidencia se valida con visión por computador.

ODS relacionados: 11 (Ciudades sostenibles), 12 (Producción y consumo responsables), 13 (Acción por el clima).

## Stack
- React Native + Expo (Android / iPhone vía Expo Go)
- Supabase (auth, base de datos, almacenamiento, Edge Functions)
- Google Cloud Vertex AI (Gemini) para validar fotos

Estado: en desarrollo.
